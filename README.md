# AI-Native Product Playbook

A minimal workflow for product owners and coding agents.

- Product requirements use one descriptive folder and a standalone Intent.
- Add design and implementation plans only when needed.
- Draft revisions live in Git; explicit owner acceptance means Approved.
- Progress, approval evidence and verification live in the PR.
- Routine maintenance does not create another product requirement.

Start with [the workflow](docs/workflow.md) or the [initialization Skill](skills/initialize-ai-native-project/SKILL.md). Existing files and valid authorization are preserved.
